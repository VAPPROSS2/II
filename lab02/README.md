# Лабораторная работа №2 — Решение задач NLP

Практическая работа по методичке ITMO: задания 1–10 по обработке естественного языка.

## Состав
- `lab02.py` — реализация заданий 1–10, включая fine-tuning BERT-tiny через Hugging Face Transformers.
- `lab02_data.txt` — исходный текст для тематического моделирования LDA.
- `requirements.txt` — зависимости проекта.
- `Отчет_ЛР2_NLP.docx` и `Отчет_ЛР2_NLP.pdf` — отчёт с таблицами, анализом и реальными скриншотами выполнения.
- `screenshots/` — скриншоты выполнения программы в VS Code.

## Запуск
```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 -u lab02.py
```

Для задания 10 загружается GLUE/SST-2, используется `prajjwal1/bert-tiny`, выполняется дообучение в течение 3 эпох и рассчитываются Accuracy и F1. Официальный test split SST-2 не содержит открытых меток, поэтому для независимой проверки используется размеченный validation split (872 примера).

## Результаты
Результаты запуска сохраняются в `lab02_results.json`. Обученная модель сохраняется локально в `artifacts/bert_tiny_sst2/` и не включена в репозиторий из-за размера.
