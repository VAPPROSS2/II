# Лабораторная работа №2 — Решение задач NLP

- Дисциплина: Современные методы искусственного интеллекта
- Выполнил: Аннин Макар Дмитриевич, группа К3320, ИСУ 465018
- Тема: обработка естественного языка (NLP)

В работе выполнены задания 1–10: токенизация, стемминг, лемматизация, разбиение текста на чанки, Bag of Words, классификация текстов, определение грамматического рода имён, сентимент-анализ, тематическое моделирование LDA и дообучение BERT-tiny.

## Файлы проекта

- lab02.py — код заданий 1–10.
- lab02_data.txt — данные для задания с тематическим моделированием LDA.
- lab02_results.json — сохранённые результаты выполнения.
- requirements.txt — необходимые библиотеки Python.
- show_results.py — просмотр сохранённых результатов.
- Отчет_ЛР2_NLP.docx и Отчет_ЛР2_NLP.pdf — итоговый отчёт.
- screenshots/ — реальные скриншоты работы программы в VS Code.
- artifacts/bert_tiny_sst2/ — файлы обученной модели BERT-tiny и токенизатора.

## Запуск

Установить зависимости:

    py -3.11 -m pip install -r requirements.txt

Запустить все задания:

    py -3.11 -u lab02.py

Если нужно выполнить только задания 1–9, не запуская повторное обучение BERT-tiny:

    py -3.11 -u lab02.py --skip-transformer

Чтобы повторно запустить только задание 10, предварительно сохранив результаты заданий 1–9:

    py -3.11 -u lab02.py --only-transformer

## Задание 10

Для классификации тональности использована модель prajjwal1/bert-tiny и набор данных GLUE / SST-2. Обучение выполнялось в течение трёх эпох. В качестве независимой проверки использована размеченная validation-часть SST-2 из 872 примеров, так как метки официальной test-части не опубликованы.

Части файла весов модели находятся в artifacts/bert_tiny_sst2/. Чтобы восстановить единый файл model.safetensors, выполните из корня репозитория:

    py -3.11 lab2/artifacts/bert_tiny_sst2/rebuild_model.py

Результаты выполнения заданий сохраняются в lab02_results.json.
